# Network B — Laptop B (standalone)

Generated by `scripts/export_standalone.py` in the combined repo. Do not edit by
hand; re-run the exporter to regenerate.

Network B watches its own OAI CN5G for UE attachment, fetches the UE's
behavioural summary from Network A, consults the RAG knowledge base, and makes an
LLM + safety-floor access decision served on **:8002**.

The shared data contract (summary schema, AMF parser, UE pseudonymiser, and the
request signer) lives in `network_b/contract/`, vendored from Network A by the
exporter — this folder has no source-level dependency on Network A.

## Run

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # set NETWORK_A_URL=http://<laptop-A-ip>:8001 and HMAC_SECRET_KEY
uvicorn network_b.api.app:app --host 0.0.0.0 --port 8002
```

`HMAC_SECRET_KEY` MUST match Laptop A's. Network A must be reachable at
`NETWORK_A_URL`.

## Signed summary channel

When Network B pulls a summary from Network A it **signs the outbound request**
and **verifies Network A's response signature** before trusting the body
(`network_b/contract/request_signer.py`, byte-identical to Network A's source of
truth). With `REQUIRE_SIGNED_REQUESTS=true` (the default), a missing or invalid
response signature **fails closed**: the UE is dropped to **T1 (restricted)** via
the same no-summary path used when Network A is unreachable.

Scheme: HMAC-SHA256 over `version∥method∥path∥timestamp∥nonce∥sha256(body)`,
carried in `X-Sig-*` headers, with a 5-minute skew window and in-memory nonce
replay cache.

**v1 scope / follow-up:** Network B's own `/v1/access/request` endpoint is
localhost / same-trust-zone and is left **unsigned** in v1. Signing that link
(so the attachment watcher and any local caller must also authenticate) is a
planned follow-up.
